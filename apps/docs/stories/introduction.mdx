# Plume UI React

A lightweight, framework‑agnostic design system for React. Components ship their
own scoped styles and are themed entirely through CSS variables, so they adapt to
your brand and flip between light and dark without any runtime color math.

- **Themeable** — every design token is a CSS variable emitted by `<ThemeProvider>`.
- **Light & dark** — built in, driven by a single `colorMode`.
- **Framework‑agnostic** — use the components as they are, or set `variant="unstyled"`
  and bring your own Tailwind / Bootstrap classes.
- **Typed** — written in TypeScript, with React 18 and 19 support.

## Installation

```sh
# npm
npm install plume-ui-react
# yarn
yarn add plume-ui-react
# pnpm
pnpm add plume-ui-react
```

`react` and `react-dom` (>= 18) are peer dependencies. `plume-ui-react` is the only
package you need: it includes every component, the theme (`ThemeProvider`, `useTheme`,
tokens and types), the hooks and the utilities.

## Quick start

Wrap your app in `<ThemeProvider>` and import the stylesheet once:

```tsx
import { Button, ThemeProvider } from 'plume-ui-react'
import 'plume-ui-react/styles.css'

export function App() {
  return (
    <ThemeProvider>
      <Button colorScheme='primary' label='Get started' />
    </ThemeProvider>
  )
}
```

### Only the CSS you use

`plume-ui-react/styles.css` has the CSS of every component (about 20 KB gzipped). To load only some of them, import
`plume-ui-react/tokens.css` once, with the default theme, and then the stylesheet of each component instead of
`styles.css`. Each one brings the CSS of the components it renders, so `css/button.css` also carries the `Spinner`, and
`css/paginator.css` the `Button`, the `Select` and the `Chip`:

```tsx
import 'plume-ui-react/tokens.css'
import 'plume-ui-react/css/button.css'
import 'plume-ui-react/css/input.css'
```

The files of the parts are the ones of the component (`css/modal.css` styles `ModalContent`, `ModalHeader`...). The
imports between the sheets are plain CSS `@import`. `tokens.css` is not one of them, so a bundler that does not
remove the repeated imports does not copy the tokens in every sheet. Do not mix them with `styles.css`: it already has
everything.

### Theming

`theme` is a deep‑partial of the default theme, so you override only what you need:

```tsx
<ThemeProvider theme={{ colors: { primary: { 500: '#5263ff' } } }}>
  <App />
</ThemeProvider>
```

### Dark mode

Pass `colorMode`, or let it follow the operating system with `"system"`:

```tsx
<ThemeProvider defaultColorMode='system'>
  <App />
</ThemeProvider>
```
