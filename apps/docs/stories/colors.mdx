## Customization

> To customize the color palette, either modify the base colors or create new colors, we do the following:

1 - Wrap your app in `<ThemeProvider>` and pass your theme overrides:

<Source code={`import { ThemeProvider, type DeepPartial, type Theme } from 'plume-ui-react'

const userTheme: DeepPartial<Theme> = {
  colors: {
    primary: {
      '50': '#e8f1ff',
      '100': '#d5e4ff',
      '200': '#b3ccff',
      '300': '#85a8ff',
      '400': '#5676ff',
      '500': '#2f45ff',
      '600': '#0c0eff',
      '700': '#0000ff',
      '800': '#0609cd',
      '900': '#10169f',
      '950': '#0a0b5c',
    }, // overwrite primaryColor
    salmon: {
      '50': '#fef3f1',
      '100': '#fee6e2',
      '200': '#fdd0c9',
      '300': '#fcb0a5',
      '400': '#fb9588',
      '500': '#fa8072',
      '600': '#f06a5a',
      '700': '#e25a49',
      '800': '#bf4333',
      '900': '#8f3329',
      '950': '#4d1712',
    },
  },
}

export function App({ children }) {
  return <ThemeProvider theme={userTheme}>{children}</ThemeProvider>
}`} dark />
In this example we are modifying the primary color and creating new color.

Solid backgrounds (such as filled buttons) use the first of the `500`, `600` and `700` shades that reads well under white text, and keep `500` with dark text when none does. That is why `salmon` keeps its light `500` as the button color, while a darker ramp would give a darker button.

2 - If you use typescript and have created new colors,
you should also do the next step so that those colors are inferred.
In the example we are using typescript's <strong>Module Augmentation</strong> to make this possible.
This code can be placed in a new definition file or if you already have a global definition file add the code there.
The augmentation targets `plume-ui-react`, the same package you import the components from.

<Source code={`// typings.d.ts  
import { ColorPalette, ShadeLevel } from 'plume-ui-react'

declare module 'plume-ui-react' {
  interface ColorPalette {
    salmon: ShadeLevel
  }
}
`} dark />
