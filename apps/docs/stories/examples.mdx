# Examples

The stories show each component on its own. These two apps show them working together in a real project. Both are
standalone apps that install the **published `plume-ui-react` package** from npm, not the workspace sources, so what you
see is what your own app gets. Both use a custom theme: a `primary` override and a new `salmon` color scheme, typed with
module augmentation.

## Next.js App Router

The Plume Projects dashboard with a simulated sign in, a sidebar, a top bar, a table with sorting and
filters, a detail drawer, a team directory and settings. It shows that `ThemeProvider` can be rendered from the root
layout, a Server Component: the color mode comes from a cookie and the server renders it, so dark mode has no flash.

- <a href='https://plume-ui-react.vercel.app' target='_blank' rel='noopener noreferrer'>Open the live demo</a> (sign in with any email and a password of 6 or more characters)
- <a href='https://github.com/darioegb/plume-ui-react/tree/main/apps/example-next-app' target='_blank' rel='noopener noreferrer'>Read the source</a>

## Vite

A client-only Vite and React SPA with a slice of the same Plume Projects product, without a server or a sign in: a
responsive sidebar and top bar, a dashboard, a projects table with filters, sorting and a detail drawer, and more. It shows
where `ThemeProvider` and `ToastProvider` go in a client-side app, how to import the bundled stylesheet and how to pass
a custom theme.

<OpenInStackBlitz />

It opens in StackBlitz, to edit it in the browser with nothing to install. <a href='https://github.com/darioegb/plume-ui-react/tree/main/apps/example-vite' target='_blank' rel='noopener noreferrer'>Read the source</a> on GitHub.
