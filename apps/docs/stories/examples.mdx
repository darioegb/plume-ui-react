# Examples

The stories show each component on its own. These two apps show them working together in a real project. Both are
standalone apps that install the **published `plume-ui-react` package** from npm, not the workspace sources, so what you
see is what your own app gets. Both use a custom theme: a `primary` override and a new `salmon` color scheme, typed with
module augmentation.

## Next.js App Router

The Plume Projects dashboard with a simulated sign in, a sidebar, a top bar, a table with sorting and
filters, a detail drawer, a team directory and settings. It shows that `ThemeProvider` is **SSR/RSC-safe**: the theme is
serialized to CSS variables and rendered on the server from a cookie, so dark mode has no flash.

- [Open the live demo](https://plume-ui-react.vercel.app) (sign in with any email and a password of 6 or more characters)
- [Read the source](https://github.com/darioegb/plume-ui-react/tree/main/apps/example-next-app)

## Vite

A client-only Vite and React SPA with a slice of the same Plume Projects product, without a server or a sign in: a
responsive sidebar and top bar, a dashboard, a projects table with filters, sorting and a detail drawer, and more. It shows
where `ThemeProvider` and `ToastProvider` go in a client-side app, how to import the bundled stylesheet and how to pass
a custom theme.

<OpenInStackBlitz />

It opens in StackBlitz, to edit it in the browser with nothing to install. [Read the source](https://github.com/darioegb/plume-ui-react/tree/main/apps/example-vite) on GitHub.
